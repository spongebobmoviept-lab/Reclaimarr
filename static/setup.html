How do I find my Plex token?
  1. Open the Plex Web App and start playing any movie or show.
  2. Click the ⋯ (more) menu on the player and choose Get Info.
  3. In the panel that opens, click View XML in the bottom-left corner.
  4. A new tab opens — look at its address bar for X-Plex-Token=.... Everything after the = is your token.

Where do I find my Radarr API key?
In Radarr, go to Settings (left sidebar) → General → the Security section near the bottom. Your API key is shown there with a copy button.

Where do I find my Tautulli API key?
In Tautulli, go to Settings → Web Interface → scroll to the API section and make sure it's enabled. Your API key is shown there.
How do I get a Discord webhook URL?
In Discord: Server Settings → Integrations → Webhooks → New Webhook → pick a channel → Copy Webhook URL.
